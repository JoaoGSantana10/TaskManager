# TaskManager
 A ideia é desenvolver uma aplicação em Spring Boot que utilize uma Task, a Task é uma entidade de tarefa. A ideia é ter um ID, uma descrição um título e um estado. Esses estados podem ser pendente em progresso e concluído. E teremos uma API que vai transicionar estados, vai atualizar tarefas, criar tarefas, listar tarefas e remover tarefas utilizando Sprint Boot..
